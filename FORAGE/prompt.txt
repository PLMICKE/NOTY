La création d'un devis doit aussi insérer automatiquement un enregistrement dans demande_status
avec l'iddemande du devis créé et idstatus = 1 (statut "Créé").
Le montant_total du devis est calculé automatiquement côté frontend (somme des montants
des lignes de détail) et envoyé avec la requête — il ne doit pas être saisi manuellement.

Champs du formulaire :

Demande : dropdown (liste des demandes depuis la table demande, afficher id + lieu)
Type de devis : dropdown (liste depuis typedevis)
Date : date picker (défaut = aujourd'hui)
Montant total : champ en lecture seule, calculé automatiquement = somme des montants des lignes de détail
Lignes de détail (details_devis) : section dynamique :

Chaque ligne contient : libelle (texte) + montant (nombre)
Bouton [+] pour ajouter une nouvelle ligne
Bouton [-] sur chaque ligne pour la supprimer
Minimum 1 ligne obligatoire
Le total se recalcule en temps réel à chaque modification de montant



Comportement à la soumission :
Dans une transaction unique :

Insérer dans devis (id_typedevis, iddemande, date, montant_total)
Insérer toutes les lignes dans details_devis (iddevis, libelle, montant)
Insérer dans demande_status (iddemande, idstatus = 1)


Et pour ta question sur le JS : un minimum de JS est recommandé pour les lignes dynamiques. Sans JS, il faudrait soit un nombre fixe de lignes pré-rendues (peu pratique), soit un rechargement de page à chaque ajout/suppression via un formulaire POST intermédiaire — ce qui alourdit l'UX. Quelques lignes de JS vanilla (sans framework) suffisent amplement pour gérer l'ajout/suppression de lignes et le calcul du total en temps réel, tu peux donc préciser dans ton prompt :

Utilise du JavaScript vanilla minimal uniquement pour la gestion dynamique des lignes de détail (ajout, suppression, calcul du total). Pas de framework JS.
